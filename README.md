# スズメの社会クイズ

小学 3〜6 年生が、社会を 4 択クイズで楽しく学べる Web アプリです。
サーバーは不要で、ビルドした静的ファイルを置くだけで動きます。
作りと見た目は、姉妹アプリの [Wordlynx](../wordlynx/) に合わせてあります。

- 学年は 3〜6 年生。タイトル画面で切りかえ (学習指導要領の社会科の内容に合わせた 38 単元・約 500 問)
- 図を見て答えるクイズ: 地図記号 (3 年)、都道府県の形・県庁所在地・ちしき (4 年)、国旗 (6 年) の 14 単元。図鑑 (一覧) ページつき
- 今日のチャレンジ: 日本時間の日付と学年から、毎日 10 問を自動でえらぶ。同じ日・同じ学年はだれが開いても同じ問題。
  図やちしきの単元がある学年 (3・4・6 年) は、そこから 3 問、ふつうの単元から 7 問
- 単元の練習: 単元ごとに 10 問。10 問中 8 問正解でクリア。何回でもやりなおせる (日がかわると問題と順番が変わる)
- 答えるたびに、正解と解説が出る。終わったら、10 問をまとめてふりかえれる
- スタンプカード: 今日のチャレンジを最後までやるとスタンプが 1 個。続けるとポイントがたまり、スズメのカード (20 種類) と交換できる
- 記録はブラウザ (localStorage) に保存。Google でログインすると Firestore に保存され、ほかのブラウザや端末でも同じ記録で遊べる (ログインは任意)

## 使い方

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果の確認
```

## スタンプ・ポイント・スズメカード

- 今日のチャレンジを最後までやると 20pt (学年・日付ごとに 1 回)。単元の練習は 8 問以上の正解で 20pt (単元ごとに 1 回)
- スタンプは学年に関係なく 1 日 1 個。どの学年でも、今日のチャレンジを最後までやると押される
- 7 日連続するたびに 1000pt (とぎれたら数え直し)
- その月の 1 日から末日まで全部そろうと、さらに 5000pt (月ごとに数える)
- カードは 40pt から 3000pt までの 20 枚で、合計 28,420pt。持っていないカードは裏向きで、必要な pt だけが見える
  - 今日のチャレンジを毎日やると、はじめの 5 枚は 2 週間以内 (2・6・7・7・14 日目) に手に入る
  - 全部集めるには、いちばん多くポイントをもらう人でも 80 日かかる
  - 値段を変えるときは、`tests/rewards.test.ts` の「カードの値段のバランス」が通ることを確かめる

ポイントは合計を保存せず、スタンプの日付とクリアの記録から毎回計算します (`src/core/rewards.ts`, `src/core/storage.ts`)。
カードの種類と値段は `src/data/cards.ts`、スズメの絵は `src/ui/sparrow.ts` にあります。

`npm run dev` を実行して `http://localhost:5173/cards.html` を開くと、全部のカードの表と裏面を一覧できます
(開発用のページで、`npm run build` の出力には入りません)。

日付は端末の時計 (日本時間に換算) で決まるので、時計を変えれば先の日のスタンプも押せてしまいます。

## 問題を追加する

手書きの問題は、`src/data/questions/g3.ts` 〜 `g6.ts` に、単元ごとに 1 行 1 問で書きます。

```
問題文|正解|まちがい|まちがい|まちがい|解説
日本には、都道府県が 全部で いくつ あるでしょう。|47|43|45|50|1都、1道、2府、43県で、合わせて 47 です。
```

- 1 つ目の選択肢が正解。出すときに自動でならべかえる
- ふりがなは `漢字(かんじ)` と半角かっこで書く。ふりがなは、かっこの前に続く漢字全体に付くので、
  熟語の一部だけに付けたいときも、熟語全体の読みを書く (`工業生産額(こうぎょうせいさんがく)`)
- 3 年生の問題は、3 年生までに習わない漢字にかならずふりがなを付ける (テストが確かめる)。
  4〜6 年生の問題は、その学年までに習わない漢字に付ける (こちらは目で確かめる)
- 単元を足すときは、ファイルの最後の配列 (`G3` など) に加える。単元の id は `g学年-英小文字`
- `npm test` が、書式・重複・問題数・ふりがなを検査する

問題を追加・変更すると、その日以降の「今日のチャレンジ」の内容が変わります。
統計の数字 (人口、生産量の順位、自給率など) は年によって変わるので、ときどき見直してください。

## ログインと記録の保存 (Firebase)

仕組みは Wordlynx と同じです (くわしい説明と「ログインできないとき」は Wordlynx の README を参照)。

- 画面はいつも手元 (localStorage) の記録を読み書きする (`src/core/storage.ts`)。
  ログインなしの記録は `shakai:v1:…`、ログイン中の人の写しは `shakai:u:<uid>:…`
- ログイン中は、書きかわった分を少しまとめてから Firestore に送る (`src/cloud/sync.ts`)。
  ログインしたとき・ページを開いたときは、Firestore の記録と手元の写しを合わせて、両方に書く (`src/core/merge.ts`)
- ログインしたとき、その端末にログインなしの記録があれば、アカウントにうつすかどうかを聞く。ログアウトすると、その人の写しは端末から消す
- **Firebase の設定を入れていないビルドでは、ログインの入り口は出ず、Firebase のコードも読みこまれません**

Firestore の形は、小学生向けの学習アプリで共通です。このアプリの `appId` は `social-studies-quiz` なので、
Wordlynx と同じ Firebase プロジェクトを使っても、記録はアプリごとに分かれます。

```
users/{uid}                                   その人の情報 (名前・メールアドレス・写真は保存しない)
users/{uid}/apps/social-studies-quiz          スタンプの日付 (activeDays)、クリアしたクイズ (completed)、
                                              持っているカード (inventory)、設定 (settings: 学年・音)
users/{uid}/apps/social-studies-quiz/progress/{クイズの id}   クイズの途中経過 (えらんだ答え)
```

設定値は `config.js` (手元) か、同じ名前の環境変数 (GitHub Actions では Variables) で入れます。
`config.js` は `.gitignore` に入っています。

```js
const FIREBASE_API_KEY = '…';
const FIREBASE_AUTH_DOMAIN = '….firebaseapp.com';
const FIREBASE_PROJECT_ID = '…';
const FIREBASE_APP_ID = '…';
const GTM_ID = 'G-XXXXXXXXXX'; // アクセス解析 (入れなければタグは埋め込まない)
```

Firebase コンソールでは、Authentication で Google ログインを有効にし、承認済みドメインに公開先を足し、
Firestore のルールに `firestore.rules` の内容を設定します。

エミュレーターでためすとき (Java が必要):

```sh
npx firebase-tools emulators:start --only auth,firestore --project demo-shakai
FIREBASE_API_KEY=x FIREBASE_AUTH_DOMAIN=localhost FIREBASE_PROJECT_ID=demo-shakai FIREBASE_APP_ID=x FIREBASE_EMULATOR=1 npm run dev
```

## 構成

- `src/core/quiz.ts` 出題 (今日のチャレンジ・単元の練習。種が同じなら結果も同じ)
- `src/core/rewards.ts`, `src/core/storage.ts` スタンプ・ポイント・カードと、手元の記録
- `src/core/merge.ts`, `src/core/snapshot.ts` 記録を合わせる決まりと、Firestore に保存する形
- `src/cloud/` ログインと Firestore との同期 (Firebase に依存するのは `firebase.ts` だけ)
- `src/data/questions/` 問題 (`g3.ts`〜`g6.ts` は手書き、`figures.ts` は図やちしきの単元)、`src/data/cards.ts` カード
- `src/ui/` ホーム、クイズ、図 (`figure.ts`)、図鑑、スタンプカード、カード、スズメの絵
- `tests/` 問題データの検査、1 年分の今日のチャレンジ、ポイント、記録の合わせ方、同期
